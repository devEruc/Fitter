# CONTRIBUTION

Thank you for your interest in contributing to this project.

### Before you begin

* Read the README.md file to avoid problems when contributing.

* Check if a related issue already exists.

* Keep your code consistent with the current project style.

# How to contribute

### Report bugs

When creating an issue, include:

* Operating system.

* Compiler used.

* Steps to reproduce the problem.

* Relevant error messages.

### Propose features

Describe:

* What problem it solves.

* How it would work.

* Possible alternatives.

### Submit pull requests

1. Create a fork of the repository.

2. Create a new branch.

3. Make your changes.

4. Verify that the project compiles correctly.

5. Commit your changes.

6. Submit a pull request.

## Code Style

### C++

* Use descriptive names.

* Keep functions small and readable.

* Document public APIs.

* Functions should perform a single task.

* Avoid unnecessary code (padded code).

* If there are exceptions and you cannot add descriptive documentation or comments, ensure that the functions are understandable.

## Dependencies

Current dependencies:

* GLFW
* GLAD
* GLM
